# Galdus Tech Day 2027 · lavoro in squadra

Repository del Lab 4 (Lezione 2, “GitHub e lavoro in squadra”) del modulo Git, corso Galdus Software Developer 2026-2027. Contiene il sito di un evento fittizio, il Galdus Tech Day 2027, così com’è alla fine della Lezione 1.

Ogni squadra ne fa il fork e aggiunge tre interventi al programma del pomeriggio, ognuno con un’issue, un branch e una pull request revisionata da un compagno. Le regole sono in [`CONTRIBUTING.md`](CONTRIBUTING.md), le versioni in [`CHANGELOG.md`](CHANGELOG.md).

Per vedere il sito apri `index.html` con un doppio clic: si apre nel browser, non serve un server.

| File | Che cosa contiene |
| --- | --- |
| `index.html` | La home dell’evento |
| `programma.html` | La tabella del programma: qui si aggiungono gli interventi |
| `relatori.html` | La pagina dei relatori |
| `css/stile.css` | Il foglio di stile |

Tutti i nomi di relatori, aziende e membri delle squadre sono inventati.
